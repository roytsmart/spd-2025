# spd-2025
Presentation for my talk at the 2025 meeting of the American Astronomical Society, Solar Physics Division.

## The slides on the web

https://roytsmart.github.io/spd-2025/ shows the slides, and the PDF is at
https://roytsmart.github.io/spd-2025/spd_2025_smart_ccd_noise.pdf.
The web version is built from the deck with
[pptx-to-html](https://github.com/roytsmart/pptx-to-html):

```bash
pptx-to-html spd_2025_smart_ccd_noise.pptx docs \
    --title "The Noise Measured by Back-illuminated Silicon Sensors" \
    --subtitle "AAS/SPD 2025 · the slides as they were presented"
```
